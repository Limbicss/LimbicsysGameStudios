## Unverified at runtime (no Codex/AGY binary in the build environment)
Docs say so, but nothing here was executed inside the real tools: Codex hook trust prompt (`/hooks`), `.codex/rules` load, `name` with hyphens in agent TOML, AGY brace-less glob matching, AGY `commandExecutionPolicy: off`, AGY skills colliding with built-in slash names (e.g. `help`, `settings`), and the AGY `.agents/hooks.json` command working directory. First run in each tool should check those.
